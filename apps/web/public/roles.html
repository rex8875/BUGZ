Roles & Permissions

Roles

Bot permissions are linked directly to this server's own Discord roles — there's no separate role to create here. Pick one of your existing Discord roles below and choose what it can do. Anyone holding that role gets these permissions immediately, checked live against Discord; remove the role from them in Discord and access is gone just as fast.

Command Permissions

By default, every command follows this server's normal role permissions above. You only need to touch anything here if you want a specific command restricted to specific Discord roles — like Dyno's per-command role restrictions — regardless of someone's normal permissions.

Ban

Real membership lives in Discord itself — check your server's own member list there for who's actually in the server. Use this to block someone from the bug tracker specifically, regardless of what Discord role they hold.
